Политика конфиденциальности

Приложение «Таблица». Действует с 31 октября 2026 года.

Какие данные хранятся

Записи, которые вы вносите в приложение, хранятся в файле на вашем устройстве. У приложения нет своего сервера, аналитики и рекламы. Никакие данные не передаются разработчику или третьим лицам.

Google Диск

Синхронизация включается только по вашему выбору. Тогда приложение просит доступ drive.file и видит только файл, созданный им самим. Остальные файлы на вашем Диске ему недоступны.

  • На Диск попадает один файл, зашифрованный AES-256 словом-ключом, которое известно только вашим устройствам.
  • Данные Google используются только для записи и чтения этого файла.
  • Токен доступа хранится на вашем устройстве и никуда не передаётся, кроме Google.

Использование и передача приложением данных, полученных от API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как удалить данные

Отключите синхронизацию в разделе «Данные» и удалите файл с Диска. Доступ приложения можно отозвать на странице разрешений аккаунта Google. Данные на устройстве удаляются вместе с файлом сохранения или приложением.

Privacy policy

The “Таблица” app. Effective October 31, 2026.

Everything you enter stays in a file on your device. The app has no server, analytics or advertising, and sends no data to the developer or third parties.

Sync is optional. When you turn it on, the app requests the drive.file scope and can only see the one file it created. That file is encrypted with AES-256 using a key word known only to your devices. Google user data is used solely to read and write this file. The access token stays on your device and is sent only to Google.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

To remove your data, turn off sync, delete the file from Drive and revoke access on your Google Account permissions page. Data on the device is removed with the save file or the app.
